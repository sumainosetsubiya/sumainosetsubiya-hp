# 実際の顧客とのやり取りの分析（2026年9月11日）

くらしのマーケット経由・キッチン水栓交換（2026年8月8日〜15日）の実例をもとに、
**依頼主が既にできていること**と**足りないこと**を整理した。

---

## 既にできていること（変えないこと）

### 追加料金を「条件と金額」で事前提示している

実際に送っている内容：

```
※※追加料金の目安※※
天板裏補強板補修              2,000円
穴径変換アダプター使用(一か所)  3,000円
穴径拡大加工                  3,000円
ワンホール水栓切断撤去         3,000円
止水栓交換(一か所)            5,000円
```

**これが特定商取引法上の防波堤そのものになっている。**
消費者庁は「◯円〜」とだけ表示して現場で高額請求する類型を、
請求訪問販売の適用除外にあたらないと名指しで否定している。
条件と金額を1対1で、訪問前に提示していれば、現場で起きるのは
**事前に合意した条件の成否の確認**にとどまり、新たな契約の締結にならない。

**法律から設計したひな形と、中身が一致していた。** 依頼主は法律を知らずに、
客に親切であろうとした結果として正解に辿り着いている。**ここは変えない。**

### その他、既に良い運用

| やっていること | なぜ良いか |
|---|---|
| 交換場所の写真を事前にもらう | 追加費用の発生確率そのものを下げている。当日の想定外＝訪問販売化リスクの芽を摘む |
| 「ご返信をもって予約確定」 | 契約がメッセージ上（＝営業所等以外の場所ではない）で成立した証拠になる |
| 駐車スペースの有無を事前に確認 | 駐車場代という追加費用を事前合意の枠に入れている |
| 写真利用の許諾を取り、断られたら即座に引き下がる | 個人情報・肖像の扱いとして誠実。実際に「公開使用を控えて」と言われ、その通りにしている |
| 口コミ依頼が全員一律・見返りなし | Googleもくらしのマーケットも、この形なら規約に沿う。特定の客だけに依頼する（レビューゲーティング）は明確に禁止 |

## 足りていないこと（足すべき4点）

### ① 保証の説明が「作業後」になっている

現状、商品保証2年・施工保証1年を**工事完了後のメッセージで初めて伝えている**。

**契約前に移すべき。** 理由は2つ。

- **売り文句として強い。** 相見積もりの場面で「保証2年付き」は決め手になる。
  終わってから伝えても、受注には1円も効いていない。
- 法的にも、建設業法19条の法定記載事項⑬「契約不適合責任」の取り決めとして、
  事前提示が筋。

### ② 支払い方法・時期が書かれていない

くらしのマーケット側で決済の流れが決まっているため省略されているが、
**自社サイト経由の客には必ず必要**（特商法11条の広告表示事項でもある）。

### ③ キャンセルの取り決めがない

「商品発注後のキャンセルは商品代の実費をご負担いただく場合があります」
といった取り決めがないと、実際に起きたときに請求できない。

### ④ 建設業法19条の4項目

不可抗力／第三者損害／遅延損害金／紛争解決。毎回同じ文でよいので、
末尾に定型文として付けるだけでよい。詳細は `quote_email_template.md` を参照。

## 検討事項

### 当日朝の「本日◯時に伺います」の一言

実例では、9時の約束に対して **9時06分に「状況如何でしょうか？」** という
メッセージが入っている（送り主は要確認）。もし顧客からのものなら、
**当日の朝に一言送るだけで防げる不安**だった。

作業の質とは無関係だが、**印象と口コミに効く。**
