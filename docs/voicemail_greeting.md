# 留守番電話の応答メッセージ

公開用の電話番号（povo）にかかってきた着信を、本人が出られない時間帯に受けるための案内音声。
AI音声合成（Irodori-TTS）で生成して流し込む。

**【2026年9月24日改訂】メール誘導型に切り替えた。** 旧版は末尾の「旧版」を参照。

---

## なぜメールへ誘導するのか（依頼主の判断・2026年9月24日）

1. **電話は「言った・言わない」が起きやすい。** 文面なら証拠が残る
2. **電話で聞いた内容はメモしなければ消える。** 現場に追われて失念すれば客に迷惑がかかる
3. **法的にも、これが依頼主の防波堤になっている。**
   追加料金の目安を条件と金額で事前に文面で伝えている運用が、特定商取引法上の
   「現場で新たな契約を結ぶ訪問販売」化を防いでいる（`customer_message_analysis.md` 参照）。
   **電話で見積もりを口頭でやると、その証拠が消える。**
4. 写真を添えてもらえるため、**メールの方が見積もりが正確で速い**

**→ 電話を切り捨てるのではなく、「記録が残るから安心」という利点として伝える。**

---

## 設計方針

1. **最初の3秒で「かけ先が合っている」と分かること。** 名乗りを最優先に置く
2. **くらしのマーケットの線引きを、会話が始まる前に済ませること。**
   本人が電話に出ないからこそ、断りづらさが発生しない
   （くらしのマーケットで依頼を受けたことがある客との直接取引はNG）
3. **メールへの誘導は「理由 → 行き先 → 得すること」の順に言う。**
   理由を先に言わないと、客には「たらい回し」に聞こえる
4. **メールが使えない客への逃げ道を必ず残す。**
   高齢の依頼者が多い。完全に閉じると、その分だけ仕事を失う
5. **冒頭を長くしない。** 長いほど本命の客が切る。営業電話よけの一文は入れない
6. 専門用語を使わない

## note

- **メールアドレスを読み上げない。** 電話口で聞き取ってメモするのは、まさに依頼主が避けたい行為。
  **「住まいの設備屋さん」で検索**という言い方なら、聞き間違えようがなく、
  屋号での検索が増えればSEOにも効く（現状、屋号での検索は0件）
- **「本日中に折り返し」は使わない**（2026-09-09にユーザーが判断）。
  現場の状況によっては当日中に折り返せない。**守れない約束は、電話に出ないことより印象が悪い**
- **「通常1〜2営業日でご返信」はサイトの記載（`contact.html`）と一致させてある。**
  片方だけ変えないこと
- **録音の告知は法的義務ではない**（個人情報保護委員会FAQ Q1-10で確認済み）。
  短縮版では尺のため省いている。入れておくほうがトラブルになりにくい
- **AIが応答している旨は名乗っていない。** 留守番電話は一方向の案内であり、AI応答の告知は不要
  （将来AIが対話する方式に変えるなら、その時は名乗るべき）
